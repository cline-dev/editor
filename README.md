# Terminal Cloud - Ala VS Code / Codespaces / Cloud Shell

Terminal berasaskan web lengkap: Terminal emulator (xterm.js) + PTY + File Explorer + Editor.

## Cara Jalankan
npm install
npm start
# buka http://localhost:3000

## Cara Jalankan Docker
docker compose up --build

## Struktur
- server.js - Backend Express + WebSocket + node-pty
- public/ - Frontend UI ala VS Code
- workspace/ - Fail user
